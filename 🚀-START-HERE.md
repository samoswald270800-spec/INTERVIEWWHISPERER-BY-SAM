## 🚀 TO DEPLOY (3 STEPS)

### **Step 1: Setup Environment (One Time)**

Create `.env` file:
```bash
copy .env.example .env
```

Add your values (see `SETUP.md` for details):
- `OPENAI_API_KEY` - Get from OpenAI
- `REDIS_URL` - Get from Upstash (free)
- `SESSION_SECRET` - Any random string
- `ADMIN_USER` / `ADMIN_PASS` - Your login

### **Step 2: Push to GitHub**

```bash
git add .
git commit -m "Interview Whisperer - Production Ready"
git push origin main
```

### **Step 3: Deploy**

**On Render/Vercel/Railway:**
1. Connect your GitHub repo
2. Add environment variables
3. Click Deploy

**That's it!** The app will:
- ✅ Auto-install dependencies
- ✅ Auto-build React app
- ✅ Auto-start server
- ✅ Work perfectly!

## 🎯 THE BUILD PROCESS (AUTOMATIC)

When you deploy, this happens automatically:

1. **Platform detects push**
2. **Runs `npm install`** → Installs root dependencies
3. **Runs `postinstall`** → Builds React + Admin
4. **Runs `npm start`** → Starts server
5. **Server serves built React app**
6. **✅ LIVE!**

**You don't lift a finger.** Just push and deploy!

## 🆘 TROUBLESHOOTING

**"Build failed on deploy"**
→ Check environment variables are set

**"Server won't start"**
→ Verify Redis URL is correct

**"OpenAI error"**
→ Check API key and billing

**"Cannot login"**
→ Verify ADMIN_USER and ADMIN_PASS in .env
