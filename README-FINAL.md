## 🚀 HOW TO RUN

### **FIRST TIME SETUP (ONE TIME ONLY)**

1. **Create `.env` file:**
   ```bash
   copy .env.example .env
   ```

2. **Edit `.env` and add:**
   - `OPENAI_API_KEY` - Get from https://platform.openai.com/api-keys
   - `REDIS_URL` - Use https://upstash.com for free Redis
   - `SESSION_SECRET` - Any random string
   - `ADMIN_USER` and `ADMIN_PASS` - Your login credentials

   **See `SETUP.md` for detailed instructions**

### **AFTER SETUP**

**Just double-click:**
```
start.bat
```

Then visit: **http://localhost:3000**

## 📞 TROUBLESHOOTING

**"Server won't start"**
→ Make sure `.env` file exists with all required values

**"Module not found"**
→ Run `npm install` in both root and `public/` directories

**"Redis connection error"**
→ Check your `REDIS_URL` in `.env`

**"OpenAI error"**
→ Verify your `OPENAI_API_KEY` is valid

**Full details in:** `SETUP.md`
